How to use the Press Release Formatter

A simple guide. You give it one file or some text, it writes a draft press release, you check and edit it, then you save or export it as a PDF.

Before you start

Open the Press Release Formatter in your browser. Nothing is uploaded to a server. The note is built and kept in your browser on this computer. Use Chrome, Edge or Firefox.

The generator uses only the facts in your source. It does not add new numbers or ratings. Every figure and rating is checked against your source, and anything it cannot find is listed in the Review panel.

Step 1: Give the source

There are two ways to give the source. Use the tabs at the top of the left panel under Input.

OptionWhat to doFiles and text it takes
DocumentClick the box, or drop one file into it.PDF, DOCX, TXT, MD, JSON or CSV. Maximum 15 MB. Use one file only.
TextClick Text and paste or type your notes into the box.Any plain text. You can paste from Word, email or a PDF.

Step 2: Pick the engine

There are only two choices in the Engine box.

ChoiceWhat it doesWhen to use it
AutomaticUses the rules engine. It reads the source and places each part into the right section of the note. No AI is used.Use this for almost every case. It is the default.
No AI (rules only)The same rules engine, set to never use AI.Use this when you want to be sure that no text leaves your browser.
Both choices work without any AI key. The note is built from your source text only.

Step 3: Options

Source type

The Source type box has three choices.

  • Detect (default): the tool works out what the source is.
  • Existing note: pick this when the file is already a press release in ACER format.
  • Raw notes: pick this when the file is rough notes, a list of facts or a table.

If you are not sure, keep Detect.

Instructions (optional)

Type a short note in the Instructions box if you want something changed. For example: "keep the liquidity section brief". This box is optional. Leave it empty if you do not need it.

Include charts

Tick Include charts to add simple charts from the financial tables. It is off by default. See Step 8.

Date on the note

Choose Add date to print a date, or No date to print none. See Step 7.

Step 4: Generate the note

Click the green Generate note button. A short message appears at the bottom: Note built from the document without AI. The note opens on the right side of the screen.

Generating takes a few seconds for a normal file. A long PDF can take a little longer.

Step 5: Check the Review panel

Click Review in the left panel. It shows three counts.

CountWhat it means
ErrorsSomething is wrong and must be fixed before you export. For example, a rating in the headline does not match the instruments table.
WarningsSomething to check. For example, a name that is not in the source.
NotesSmall points only, such as a missing standard section.

Click any item in the list to jump to it in the note. If the list says No issues found, you can go on.

Step 6: Edit on the page

The note looks like the final PDF. Click any heading, paragraph, bullet or table cell and type. Changes are saved as you type.

When you move the mouse over a paragraph, small buttons appear on the right. They do this:

ButtonWhat it does
Up and down arrowsMoves the paragraph, bullet or table up or down in the section.
CopyMakes a copy of the paragraph, directly below it.
BinDeletes the paragraph. Use Undo if you delete by mistake.

Under the last paragraph of a section you will see Add block. Click it to add a paragraph, bullets, a table, a subheading or a driver.

Undo and Redo. Use the two arrow buttons at the top, or press Ctrl+Z to undo and Ctrl+Shift+Z to redo.

Sections can be moved or deleted from the buttons beside each section heading. Tables can have rows and columns added or removed under the table.

Step 7: Date on the note

The date sits under the PRESS RELEASE label at the top right of the first page.

  • Click Add date to show the date on the note.
  • Click No date to hide it.
  • To set the date, type it in the date box, for example 24th August 2026. Or click the calendar icon and pick a day from the calendar. The date is written in this style automatically.

Step 8: Charts

Charts are off by default. To add them, click Charts off in the top bar. It changes to Charts on. You can also tick Include charts before you generate.

Charts are drawn only from the financial tables in your source. The small numbers on the chart axis are scale marks, not new figures. Turn charts off again the same way if you do not want them.

Step 9: Pick a template

There are three templates only. They use the same text. Only the layout is different.

LetterNameWhat it looks like
ABoardroomA teal banner at the top with the rating facts, a short summary and the full note.
BScorecardA side panel with key facts, a driver table and the triggers for an upgrade or downgrade.
CReportCards for the rating, outlook, financials and highlights, followed by the full note.

To switch, click A Boardroom, B Scorecard or C Report in the top bar. The page changes at once. To compare all three, click Print view.

Step 10: Save and export

Save

Click Save in the top bar to keep a version of the note. Each save adds a new version number, so you can go back to an older one. Notes are saved only in this browser.

Library

Click Library to see your saved notes. Click a note to open it. Click Versions to pick an older version. Press Escape or the cross to close the list.

Export PDF

Click Export PDF to download the note as an A4 PDF in the template you chose. Check the note once more before you export.

JSON file

The small file button next to Save downloads the note as a JSON file. Keep it if you want a copy of the note to open again later.
